# JavaScript & Web Practice

A collection of small personal projects and experiments created while learning JavaScript, HTML and CSS.

This repository is an ongoing space for practising web development, trying out ideas and building small projects as I learn.

## Projects

### Weather App

A simple weather application where the user can enter a city and view its current temperature and humidity.

The project uses the Open-Meteo API to retrieve weather information.

**Technologies:** JavaScript, HTML, CSS, Open-Meteo API

### Colour Changer

A small JavaScript project where the user can change the colour of a square in the centre of the page.

The current colour's RGB value is displayed underneath the square. A reset button allows the colour to be returned to its original state.

**Technologies:** JavaScript, HTML, CSS

### CuteMySpace

An HTML and CSS practice project inspired by the style of old MySpace profiles.

The project was created as an early exercise in experimenting with webpage layouts, styling and creating a personalised webpage.

It is not intended to be a functional social media page and is mainly a creative learning project.

**Technologies:** HTML, CSS
